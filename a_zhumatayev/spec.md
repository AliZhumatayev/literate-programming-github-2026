# Top words specification

A news site shows a "Trending words" box beside each article. This spec defines exactly which words appear in that box and with what counts. Articles may be in English, Russian, or Kazakh (Cyrillic script), or any mix of them.

Notation: in the examples, an input is a Python string literal (except `None` and `b"cat"`), and outputs are Python values. A `\uXXXX` escape names the exact code point; invisible and look-alike characters are always written as escapes, so copying the table cannot change what it tests.

## Function

- Python 3, standard library only. File `top_words.py`, function `top_words(text: str) -> list[tuple[str, int]]`.
- Returns a `list` of at most 10 `(word, count)` tuples; `word` is a `str` in its final form (after rules 3, 6 and 11) and `count` is an `int` >= 1.
- If `text` is not an instance of `str` (`None`, `bytes`, a list, ...), raise `TypeError`. No other exception is raised for any `str` input.
- The function is pure: it does not print, read files, or modify global state.
- Reference environment: CPython 3.13, whose `unicodedata.unidata_version` is `"15.1.0"`. Every character property used by the rules (`str.isalpha()`, `str.lower()`, Unicode categories, NFC) is taken from that Unicode version. Another Python version may classify letters added in later Unicode versions differently; such inputs are outside this spec.
- There is no limit on the length of `text`. The running time is O(n log n): the function must not rescan the text once per word (for example `text.count(word)` for each word).

## Rules

The text is processed in this order: rule 11, rule 3, rule 6, then the words are found by rules 1, 2, 4 and 5, then counted by rules 7 and 12, then sorted by rule 8 and cut by rules 9, 10 and 13.

1. **Word.** A _letter_ is a character `c` with `c.isalpha()` true (after rules 11, 3 and 6). This includes Latin, Russian, and Kazakh letters (`ә ғ қ ң ө ұ ү һ і`, and capitals) and letters of other scripts. `str.isalpha()` is not the same as the regular expression `[^\W\d_]`: superscript digits (`²`), vulgar fractions (`½`) and Roman numerals (`Ⅻ`) are not letters, so they are separators.
2. **Joiners.** A _joiner_ is `-` (U+002D) or `'` (U+0027). A joiner is part of a word only if it has a letter immediately before it and a letter immediately after it; otherwise it is a separator. Formally a word is a maximal substring matching `L+ (J L+)*`. So a hyphenated compound is one word, leading and trailing joiners are dropped, two joiners in a row split the word, and a word hyphenated across a line break is two words.
3. **Apostrophes.** `’` (U+2019) and `ʼ` (U+02BC) are replaced by `'` (U+0027). No other character is mapped to `'`; `‘` (U+2018) and the backtick are separators.
4. **Digits** are separators. Numbers are never words and never part of a word.
5. **Every other character** is a separator: whitespace, underscore, punctuation, quotation marks, all dashes (en dash, em dash, U+2010 hyphen, U+2011 non-breaking hyphen; only ASCII `-` joins words), symbols, and emoji.
6. **Case.** After rule 11 and rule 3, the whole text is lowercased with `str.lower()` (not `str.casefold()`, so `ß` stays `ß`), and then every `Mn` character produced by the conversion is deleted (`İ` becomes plain `i`, not `i` + U+0307). Because the whole text is lowercased at once, Python's Unicode final-sigma rule applies to the whole text: a capital `Σ` becomes final `ς` exactly when `str.lower()` makes it so, that is, under the Unicode Final_Sigma condition: it is preceded by a cased letter and not followed by a cased letter, where *case-ignorable* characters in between are skipped. Case-ignorable characters include `'`, `.`, `:`, `^` and the backtick, but not `-`, spaces or digits. So `ΟΔΟΣ` becomes `οδος`; `Σ` before a hyphen becomes `ς` even inside a compound (`ΟΣ-Α` becomes `ος-α`); and `Σ` followed by `'` or `.` and then a letter becomes `σ` (`ΟΣ.Α` becomes `οσ.α`, which rule 5 then splits into `οσ` and `α`). Lowercasing character by character, or each word after splitting, gives different results. The word is returned in that form.
7. **No filtering.** There is no stop-word list, no minimum length, and no stemming or lemmatization.
8. **Order.** Sorted by count, highest first. Words with equal counts are sorted by the word itself in ascending code point order (Python's default string comparison).
9. **Fewer than 10 distinct words:** return all of them.
10. **No words at all** (empty text, only punctuation or digits): return `[]`.
11. **Normalization.** Before anything else, the text is normalized to NFC (`unicodedata.normalize("NFC", text)`), then every character of Unicode category `Mn` (non-spacing mark) or `Cf` (format character) is deleted. This removes combining marks that have no precomposed form with their letter, such as the Russian acute stress mark U+0301 on `о`, and invisible characters inside words (soft hyphen U+00AD, zero-width space U+200B, ZWNJ and ZWJ, word joiner U+2060, BOM U+FEFF). A mark that has a precomposed form stays part of its letter (`e` + U+0301 becomes `é`). This includes Russian stress written with a grave accent on `и` or `е`: `и` + U+0300 becomes `ѝ` (U+045D), which is a different letter from `и`, so such a word is not merged with its unstressed form. Decomposed `й` (`и` + U+0306) and `ё` (`е` + U+0308) are composed by NFC before any mark is deleted, so they stay `й` and `ё`.
12. **Exact-form counting.** Two words are the same only if their final forms are equal. `ё` and `е` are different letters; Latin and Cyrillic look-alikes are different (Latin `c` U+0063 vs Cyrillic `с` U+0441); no transliteration; a hyphenated compound does not count toward its parts.
13. **Limit.** Return the first 10 entries of the order from rule 8. Words tied with the 10th entry that come after it in that order are dropped.
14. **Unsupported scripts.** Scripts that write vowels with combining marks (Devanagari, Thai, Hebrew with points) are not supported: their `Mn` marks are deleted and their `Mc` characters split words. The output is still fully determined by the rules, but the counted words are not the real words. The same holds for scripts that do not put spaces between words (Chinese, Japanese, Thai): a whole run of letters is counted as one word.
